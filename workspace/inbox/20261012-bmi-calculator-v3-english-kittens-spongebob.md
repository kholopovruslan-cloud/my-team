## Что сделать

Новая версия калькулятора ИМТ — **на английском языке**, с обновлённым дизайном и весёлой темой: **котики и Спанч Боб**.

## Формат

- Один самодостаточный HTML-файл (встроенные CSS/JS), открывается в браузере без установки.
- Сохранить **новым файлом**: `workspace/outbox/bmi-calculator-v3.html` + отчёт `workspace/outbox/20261012-bmi-calculator-v3.md` с одной строкой передачи.
- **Не трогать** v1 и v2 — они остаются как есть.

## Обязательные требования

1. **Весь интерфейс на английском**: labels, placeholders, buttons, errors, categories.
2. **Сохранить всю логику v2** (не терять исправления):
   - категория определяется по **неокруглённому** BMI, округление — только для показа;
   - границы: `< 18.5` Underweight / `18.5–24.9` Normal weight / `25.0–29.9` Overweight / `≥ 30.0` Obese;
   - поля `type="text"` + `inputmode="decimal"`, ошибки: empty fields / not a number / must be > 0 / realistic ranges (height 30–300 cm, weight 2–600 kg);
   - `aria-live="polite"` на блоке результата;
   - дисклеймер внизу (по-английски): «BMI is only an indicator and does not replace a doctor's consultation.»
3. **Новый дизайн** (улучшение, не косметика):
   - свежая цветовая палитра, скруглённые карточки, тени, плавные анимации появления результата;
   - адаптивность под мобильные;
   - кнопки с hover/active состояниями.

## Тема: котики и Спанч Боб (креативная часть)

- Милые котики: эмодзи/CSS-арт/паттерн — как заблагорассудится, но **без внешних картинок** (файл должен остаться автономным).
- Спанч Боб:_^(спонж-жёлтый акцент, «кинематический» визуальный стиль морской темы, эмодзи 🧽🍿🦀 — на выбор).
- Идея (не обязательная): маскот-панель, которая **реагирует на результат** — например, котик/Спанч Боб радуется при «Normal weight», грустит при «Obese». Приветствуется юмор, но текстовые ошибки и дисклеймер остаются серьёзными и понятными.
- Ничего бренд-копирайта не встраивать: только эмодзи и собственные CSS-иллюстрации.

## Как выглядит «готово»

1. Весь UI — английский, ничего русского не осталось.
2. Категории и граничные значения совпадают с п.2 (проверка: 24.96 → Normal weight, 25.0 → Overweight, 29.96 → Overweight, 30.0 → Obese).
3. Ввод `abc` → «not a number»-сообщение; пустые поля → «empty fields»-сообщение.
4. Котики/Спанч Боб присутствуют, дизайн визуально лучше v2.
5. Файлы v1/v2 не изменены; всё новое — отдельными файлами в `workspace/outbox/` + одна строка передачи.
