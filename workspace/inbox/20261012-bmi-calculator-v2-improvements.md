## Что изменить (по пунктам)

1. **Категорию определять по неокруглённому значению, а не по округлённому.**
   - Сейчас: raw BMI 24.96 → округляется до 25,0 → «Избыточная масса тела», хотя по ВОЗ это ещё «Норма».
   - Нужно: сначала `if (rawBmi < 18.5) … else if (rawBmi < 25) … else if (rawBmi < 30) … else …`, а округление — только для отображения.
   - Границы категорий: `< 18,5` / `18,5–24,9` / `25,0–29,9` / `≥ 30,0` (как в задаче v1).
2. **Сообщение об ошибке «введите число» должно быть достижимым.**
   - Поля `type="number"` при вводе текста просто становятся пустыми, и пользователь видит «заполните оба поля».
   - Решение: сменить на `type="text"` + `inputmode="decimal"`, тогда нечисовой ввод ловится проверкой `isNaN` и показывается корректное русское сообщение.
   - Сохранить существующие проверки: пустые поля, не числа, ≤ 0, диапазоны (30–300 см, 2–600 кг).
3. **Добавить дисклеймер** мелким шрифтом внизу карточки, на русском, например:
   > «ИМТ — лишь ориентир и не заменяет консультацию врача.»
4. **Доступность:** добавить `aria-live="polite"` на блок результата, чтобы скринридеры озвучивали итог.

## Как выглядит «готово»

- Русский интерфейс сохранён полностью.
- Проверка на пограничных значениях: 24.96 → «Норма», 25.0 → «Избыточная», 29.96 → «Избыточная», 30.0 → «Ожирение».
- Ввод «abc» показывает сообщение про нечисловое значение (не про пустые поля).
- Дисклеймер и `aria-live` на месте.
- Старый `bmi-calculator.html` и отчёт v1 не тронуты; всё новое — отдельными файлами `-v2` в `workspace/outbox/` + одна строка передачи.
