## Что сохранить (логика из v3 — без регрессий)

- Категория по **неокруглённому** BMI: `< 18.5` Underweight / `< 25.0` Normal weight / `< 30.0` Overweight / `≥ 30.0` Obese.
- Поля `type="text"` + `inputmode="decimal"`, нормализация запятой/точки.
- Отдельные ошибки: empty fields / not a number / must be > 0 / ranges (30–300 cm, 2–600 kg).
- `aria-live="polite"` на результате, `role="alert"` на ошибке, дисклеймер внизу (English).

- Телефонная адаптация сохраняется; читаемость не должна страдать (brainrot — про вид, а не про сломанный UI).
